## 🔴 Т1. `GetForm` — принимать JSON в API (не только multipart)

**Проблема** (`helpers/http/getForm.go`): принимается только
`multipart/form-data` с полем `form` (JSON внутри). Любой внешний клиент
(curl, Postman, интеграции) обязан это знать; `Content-Type: application/json`
даёт ошибку. Это задача **portal Т4** — фикс должен быть здесь (эталон для
всех проектов).

- [ ] 1. Детект по Content-Type: `application/json` → парсить тело напрямую;
     `multipart/form-data` → текущий путь
- [ ] 2. Сохранить возврат `map[string][]*multipart.FileHeader` (файлы —
     только multipart; для JSON — пустая мапа)
- [ ] 3. Тест на оба пути (unit: httptest + gin)
- [ ] 4. Обновить portal/rdkb/pros на новую версию sprob
